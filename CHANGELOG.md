## [0.1.0] - 2026-10-09

### Added

- **Access Inspector** module: what the public, a role or a user can do in each collection, and which policy allows it.
- Item rules, field permissions, validation and presets per action, with item testing.
- **Who can access** a collection.
- **Check API Request**: whether Directus would allow a request, and why.
- **Compare** with another user or role, and **Simulate** other roles or policies.
- A Docker Compose playground.
